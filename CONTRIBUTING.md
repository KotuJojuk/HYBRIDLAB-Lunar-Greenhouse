# Contributing to HYBRIDLAB Lunar Greenhouse

Thank you for helping make educational hydroponics and space agriculture more approachable.

1. Open an issue describing the problem or proposed improvement.
2. Make focused changes to the ESP32-S3 firmware and keep user-facing Turkish text understandable.
3. Avoid modifying physical pump/fan pin mappings without hardware verification.
4. Keep NASA-derived facts **separate** from illustrative simulation parameters. Do not imply NASA validated model outputs.
5. Update documentation, screenshots, and tests as appropriate.
6. Open a pull request with your hardware configuration, ESP-IDF version, build status and evidence of testing.

Never commit Wi-Fi passwords, exported NVS partitions, device identifiers, account credentials or personal photos without permission.
