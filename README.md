## What is HYBRIDLAB Lunar Greenhouse?

HYBRIDLAB connects two complementary learning experiences:

1. **Real hydroponics:** A compact transparent ~1.9 L growing reservoir with five planting sites, an aeration pump and a touchscreen-supported plant observation log. Students can watch roots develop and manually record pH, electrical conductivity (EC), leaf color and root color.
2. **Virtual lunar greenhouse:** Two side-by-side growing chambers where students can compare lettuce, dwarf tomato and strawberry responses to pH, EC, light intensity (PPFD), photoperiod, light spectrum and temperature. The firmware shows simulated plant growth, estimated harvest mass, plots and explanations.

The virtual experiments are accelerated and run **locally on the ESP32-S3**, without requiring a cloud service.

## Features

- Five planting positions in an **X arrangement**: A1, A3, B2, C1, C3.
- ESP32-S3-based **7-inch, 800×480 LVGL touchscreen**.
- Manual daily plant and chemistry observations persisted in **NVS**.
- Local **A/B lunar greenhouse simulator** with adjustable light, nutrients and temperature.
- Fast simulated growth, visual plant development, educational questions and results graphs.
- Reference information on **NASA VEG-04 and related controlled-environment plant research**.
- Gamified activities, achievements, virtual harvest and station upgrades.
- Offline operation; optional Wi-Fi/time synchronization for device features.

### Important scientific distinction

NASA material is used as **research references and educational context**. The plant-growth responses and virtual biomass predictions are generated by an **illustrative educational model**, not NASA-validated crop-growth datasets. The VEG-04 experiments took place aboard the **International Space Station**, not on the Moon. This repository is **not affiliated with or endorsed by NASA**. See [Science and NASA references](docs/NASA_AND_SCIENCE.md).

## Hardware overview

- ESP32-S3 with compatible **7-inch RGB LCD (800 × 480)** and **GT911 capacitive touch**.
- External PSRAM and approximately **16 MB Flash** configured in the supplied firmware.
- Transparent hydroponic reservoir with five growing sites and net pots.
- Low-voltage air pump with **appropriate motor driver**; optional fan.
- Appropriate regulated power supply and wiring for the specific electronics.

The default pump/fan control signals use **GPIO19/GPIO20** in the provided source. **Verify pin assignments, voltage limits and protection components against your own board before connecting hardware.** More detail: [Hardware notes](docs/HARDWARE.md).

## Build and flash

### Requirements

- **ESP-IDF 5.5.x** (the supplied project was configured with 5.5.4)
- ESP32-S3 toolchain, CMake, Ninja and Python managed by ESP-IDF
- The hardware described above
- Enough storage and RAM for the project assets and LVGL buffers

This repository **includes local copies** of LVGL 9.1.0 and the Espressif GT911 touch components for reproducible builds. See [third-party licenses](THIRD_PARTY_NOTICES.md).

From an **ESP-IDF terminal** in the repository root:

```powershell
idf.py reconfigure
idf.py build
idf.py -p COM7 flash monitor
```

Replace `COM7` with the actual device port. The repository includes `sdkconfig` and `sdkconfig.defaults` for the target hardware.

> **Flashing caution:** The project generates a SPIFFS partition image and `idf.py flash` can overwrite SPIFFS, including previously saved simulation records. Back up important data before updating. Do **not** use `erase-flash` on a device containing data you want to keep. See [Build notes](docs/BUILD_AND_FLASH.md).

## Development notes and limitations

This project is published as an **educational development prototype**, not a certified consumer product. Do not assume that pH or EC values are automatically measured: the current plant observation workflow uses **manual entry**. Motor actuation and power circuitry must be validated on the actual board. Some legacy development tests are host-specific and require a separately configured toolchain. Independent ESP-IDF compilation and on-device verification are recommended for every release.
